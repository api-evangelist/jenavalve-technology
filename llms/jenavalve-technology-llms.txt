# JenaValve Technology

> JenaValve Technology, Inc. is a privately held medical-device company in Irvine, California,
> with an EU headquarters in Munich and a UK office in Leeds. It develops the Trilogy Heart Valve
> System, a transcatheter aortic valve replacement (TAVR) device purpose-built for the minimally
> invasive treatment of severe aortic regurgitation (AR) as well as aortic stenosis (AS).
> JenaValve operates NO developer API programme. This file is generated by API Evangelist, not
> published by JenaValve.

## Important context for agents

- **There is no JenaValve API product.** No developer portal, no documentation, no API keys, no
  SDKs, no CLI, no MCP server, no agent card, no changelog, no status page and no SLA. The
  subdomains `developer.`, `api.`, `docs.`, `status.` and `trust.` do not resolve.
- **What does exist** is the anonymously readable WordPress REST API on each of the company's two
  websites. It is an incidental side effect of the CMS, not an offering. Treat it as unversioned,
  uncommitted and liable to change without notice.
- **No credential is needed** for anything described here, and none can be obtained.
- **Do not present this as an official JenaValve integration surface.**
- The Trilogy System is CE marked and is an **investigational device** in the United States,
  limited by federal law to investigational use. Do not describe it as FDA approved.

## Useful calls

- Search all corporate content: `GET https://jenavalve.com/wp-json/wp/v2/search?search=trilogy`
- Press releases only: `GET https://jenavalve.com/wp-json/wp/v2/posts?categories=13`
- Videos: `GET https://jenavalve.com/wp-json/wp/v2/posts?categories=17`
- AR education videos: `GET https://discover-ar.com/wp-json/wp/v2/posts?categories=13`
- AR education audio: `GET https://discover-ar.com/wp-json/wp/v2/posts?categories=15`
- Downloadable PDFs: `GET https://jenavalve.com/wp-json/wp/v2/media?mime_type=application/pdf`

Keep payloads small with `?_fields=id,title,link,date` and avoid a second round trip with
`?_embed`. Maximum `per_page` is 100 — asking for more is a hard HTTP 400, not a clamp.
Pagination totals arrive only in the `X-WP-Total` and `X-WP-TotalPages` headers.
